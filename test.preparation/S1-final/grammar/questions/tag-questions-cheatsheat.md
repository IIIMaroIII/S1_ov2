" QUESTION TAGS — FULL SNAPSHOT (EXAM CHEATSHEET)

" CORE RULE
Positive statement  -> Negative tag
Negative statement  -> Positive tag

" FIXED EXCEPTIONS (MEMORIZE)
I am                -> aren’t I
Let’s               -> shall we
Imperative          -> will you / won’t you   " commands / requests (no subject)
Used to             -> didn’t
Everyone / someone / nobody -> they
Nothing / something -> it
This / that         -> it
These / those       -> they

" IMPLICIT NEGATIVES -> POSITIVE TAG
never
hardly / barely / rarely / seldom
few / little (no 'a')

" NOTE:
a few / a little     -> POSITIVE -> negative tag

" VERB-BASED TAG FORMATION
be                  -> repeat be
modal (can, will…)  -> repeat modal
present simple      -> do / does
past simple         -> did
have (auxiliary)    -> have

" QUICK EXAM MANTRA
Check verb -> check negativity -> choose pronoun -> flip polarity
